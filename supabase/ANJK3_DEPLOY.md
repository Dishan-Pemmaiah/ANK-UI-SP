# ANJK 3 deployment

1. In the existing Supabase project, ensure the `public.is_admin()` helper and `AppUsers` admin role policies from `rls.sql` or `security-hardening-2026-08.sql` are already installed. Do not replace existing Sports tables.
2. Run `migrations/20260914_anjk_hockey_seasons.sql` once if it has not yet been installed. Then run `migrations/20260914_anjk_hockey_match_control_followup.sql`, `migrations/20260914_anjk_hockey_reschedule_history_fix.sql`, `migrations/20260914_anjk_hockey_goal_corrections.sql`, and `migrations/20260914_anjk_hockey_match_notes.sql` in that order. If earlier migrations were already applied, run only those still missing. The goal-corrections migration adds the atomic scorer/goal editor and makes final score corrections reconcile active goal credit. The match-notes migration adds the public note field to existing fixtures. The migrations preserve legacy tables and existing hockey records. If a season already has multiple live matches, end or postpone the extras before relying on the one-live-match rule.
3. Optionally run `tests/hockey_standings.sql`, `tests/hockey_match_control.sql`, and `tests/hockey_goal_corrections.sql` in the SQL editor after all migrations. They check standings, the admin match lifecycle, and scorer/score corrections. All use transactions that roll back test data; run them with a database owner connection, not from the public app.
4. Deploy the React build to Netlify using the existing `REACT_APP_SUPABASE_URL` and `REACT_APP_SUPABASE_ANON_KEY` environment variables. The existing SPA redirect handles `/anjk-3` and `/admin/anjk-3`.
5. Sign in with an existing Admin account. Open `/admin/anjk-3` to enter dates, venue, poster, teams, optional players, pools, fixtures and published/draft announcements. The bundled poster is `public/anjk3/anjk3-poster.jpg`; set its CMS URL to `/anjk3/anjk3-poster.jpg`. The fixture calendar dialog selects the date and start time in IST. Use **Match Control** to start, score (optionally credit or quickly add a player to the team roster), change phase, publish a public match update, correct goals/scorers and end fixtures. The confirmed **Delete match** action in Fixtures or Match Control permanently removes that fixture and its goal events; completed results also leave standings and stats. Standings are a database view and update automatically from completed Group/League matches.

For a future season, open `/admin/tournaments/<slug>` to create its record, then share `/tournaments/<slug>` as its public page. The ANJK 3 main menu and Home panel continue to point to the ANJK 3 record.
